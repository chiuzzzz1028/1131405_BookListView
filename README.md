## 功能
1. 顯示圖書清單
2. 切換檢視方式：使用者可以透過右上方的下拉式選單切換圖書清單的顯示方式。檢視方式有：大圖示、詳細資料、小圖示等等
3. 借閱書籍：使用者可以點選左側圖書清單中的書籍，系統會跳出確認視窗詢問是否要借閱該書

5. 清空借書清單：使用者可以按下「清空清單」按鈕，一次清除所有借書紀錄
6. 離開確認：當使用者關閉程式時，系統會跳出確認視窗詢問是否確定要離開。
